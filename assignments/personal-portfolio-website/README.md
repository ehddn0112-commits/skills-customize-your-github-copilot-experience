# 📘 Assignment: Personal Portfolio Website

## 🎯 Objective

Build a one-page personal portfolio website using HTML and CSS. You will organize content with semantic HTML and use CSS to make your page clear, readable, and personal.

## 📝 Tasks

### 🛠️	Set Up the Page Structure

#### Description

Create the basic HTML document and organize your page into meaningful sections.

#### Requirements
Completed program should:

- Include a valid HTML document with a page title.
- Use a `header`, `main`, and `footer` element.
- Add a heading with your name or a portfolio title.
- Create separate sections for an introduction and your projects or interests.


### 🛠️	Add Portfolio Content

#### Description

Fill each section with information that helps a visitor learn about you and your work.

#### Requirements
Completed program should:

- Include a short introduction of at least two complete sentences.
- List at least three interests, skills, or projects.
- Add at least one image with meaningful alternative text.
- Include a link to a website, project, or resource you enjoy.


### 🛠️	Style Your Portfolio

#### Description

Use CSS to improve the visual organization and readability of your portfolio.

#### Requirements
Completed program should:

- Apply a consistent font and color scheme.
- Add spacing around sections so content is easy to read.
- Style links so visitors can identify them.
- Use at least one CSS class to style a group of related elements.
