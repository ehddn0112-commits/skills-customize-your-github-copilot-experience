# 📘 Assignment: Hangman Game Challenge

## 🎯 Objective

Build a classic Hangman game using Python strings, loops, conditionals, random selection, and user input. Players should reveal a hidden word by guessing letters before they run out of attempts.

## 📝 Tasks

### 🛠️	Create the Game Setup

#### Description
Create the data and variables your Hangman game needs before the guessing round begins.

#### Requirements
Completed program should:

- Store at least five possible words in a predefined list.
- Randomly select one hidden word from the list.
- Set a starting number of incorrect guesses remaining.
- Display the hidden word as underscores separated by spaces.


### 🛠️	Build the Guessing Loop

#### Description
Write a loop that accepts letter guesses, updates the displayed word, and ends the game with the correct result.

#### Requirements
Completed program should:

- Ask the player to enter one letter on each turn.
- Reveal each correctly guessed letter in its correct position.
- Decrease the remaining attempts only for incorrect guesses.
- Continue until the player guesses the whole word or uses all attempts.
- Display a clear win message or lose message when the game ends.
